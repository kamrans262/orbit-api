# Orbit Admin Milestone 5 — Privacy, Compliance & Support

This overlay implements the fifth Web Administration milestone on top of the green M1–M4 backend.

## Scope

- Privacy Request Center with assignment, deadlines, identity-verification state, workflow, internal notes, and audit trail.
- Automatic bridging of existing Identity data-export and account-deletion requests into privacy cases.
- Administrative data-export review, audited time-limited delivery links, revocation, failed/expired regeneration, and consumer redemption.
- Scheduled redaction of expired export payloads and expiration of delivery links.
- Account-deletion supervision using the existing Identity finalization/cancellation actions rather than arbitrary database deletion.
- Support ticket creation, search/filter/pagination, SLA, assignment, escalation, workflow, user/admin conversation, internal notes, and linked records.
- Immutable user contact history for support, privacy, moderation enforcement, and appeal decisions.
- Safe Orbit notifications for support and privacy changes.
- Granular RBAC for Support Agent and Compliance Officer.

## Privacy boundaries

This milestone does not add plaintext access to E2EE messages, Moments, encrypted media, private keys, precise Presence location, or SOS recording material.

Data export payloads remain the same server-visible safe export generated by the existing Identity module.

## Sensitive permissions

The default Super Administrator role intentionally does not receive:

- `privacy.identity.verify`
- `privacy.exports.manage`
- `privacy.exports.deliver`
- `privacy.deletions.manage`

These are separately assigned to the Compliance Officer default role.
